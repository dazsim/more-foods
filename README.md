# More Foods

More food types for Minecraft.

Adds tomatoes, lettuce, onions, cabbage, spinach, kale, garlic, leeks, peas, haricot beans, parsnips, turnips and swedes as crops (seeds drop from grass), kitchen tools (knife, pot, mixing bowl, pestle and mortar, frying pan, juicer, mincer) and a long list of foods made with them: breads, sandwiches, burgers, pizza, stews, roast dinners, a cooked breakfast and more. Cows, pigs, chickens and sheep killed by a player drop extra bits for cooking.

Built for Minecraft 26.1, 26.2 and 26.3 on NeoForge and Fabric, 1.21.1 on NeoForge and Fabric, and 1.20.1 on Forge and Fabric. With Much More Storage installed, the assembly board also sits on its cupboards and worktops.

## Cookbook

With Simple Books 1.0.1 or later installed (optional, not needed to play) there is a More Foods Cookbook: a step by step guide to every recipe, tool and crop. Craft it from a book and any More Foods seed, or get one the first time you pick up a More Foods seed or crop. Without Simple Books the book files are simply unused and the recipe and reward do not load. The pages live in `assets/morefood/simplebooks/`.

The crop models, blockstates and crop textures are generated by `tools/cropmodels.py` (Python 3 with Pillow). Run it from the repo root after changing a shape.

## Building

The build uses [Stonecutter](https://stonecutter.kikugie.dev/) so every Minecraft version and loader comes from the one source tree in `src`. Version specific values are in `stonecutter.properties.toml` and the versions built are listed in `settings.gradle.kts`.

Build with JDK 25, one node at a time, for example `./gradlew :26.1.2-fabric:build`. Jars end up in `versions/<version>-<loader>/build/libs/`. Add `-Pversion=2.1.0-alpha.1` for a test jar. `./gradlew build` builds every node and is only needed for a release.

Java that differs between versions uses Stonecutter comments (`//? if >=26.3 {`) and the string replacements in `stonecutter.gradle.kts`. Edit the source with the active project left at `26.1.2-fabric` and run `./gradlew "Reset active project"` before committing.

Data and assets whose format changed live in `src/eras/<era>` (26.3, 26.1, 1.21.1, 1.20.1) and each node picks one in its build script. Only edit `src/eras/26.1`, then run `python3 tools/gen_eras.py` from the repo root to rebuild the others.
