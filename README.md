# More Foods

More food types for Minecraft.

Adds tomatoes, lettuce and onions as crops (seeds drop from grass), kitchen tools (knife, pot, mixing bowl, pestle and mortar, frying pan, juicer, mincer) and a long list of foods made with them: breads, sandwiches, burgers, pizza, stews, roast dinners, a cooked breakfast and more. Cows, pigs, chickens and sheep killed by a player drop extra bits for cooking.

Built for Minecraft 26.1 on NeoForge and Fabric.

The crop models, blockstates and crop textures are generated by `tools/cropmodels.py` (Python 3 with Pillow). Run it from the repo root after changing a shape.
